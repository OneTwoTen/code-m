# CodeM MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a minimal Bun-based MCP server proving tool discovery, safe workspace reads, and bounded non-interactive terminal execution.

**Architecture:** A modular monolith exposes thin MCP handlers over core services. Core defines portable contracts; the Bun process adapter owns `Bun.spawn`; workspace and process policies run before operating-system access.

**Tech Stack:** TypeScript strict mode, Bun workspaces/runtime/test, Biome, MCP TypeScript SDK v1, Zod v4, GitHub Actions.

## Global Constraints

- Bun is the package manager, runtime, workspace manager, and test runner.
- Biome is the only formatter and linter.
- Core code must not import Bun or MCP packages.
- The MVP supports stdio only.
- Terminal commands use executable plus argument arrays, never shell strings.
- Tool output is bounded and reports truncation.
- Remote HTTP and container execution are outside this MVP.
